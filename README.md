# 个人记录网站

一个简单的个人记录网站，包含**日记**、**待办**、**目标**三个板块。

- 深色主题
- 数据全部保存在浏览器本地（localStorage），无需后端
- 完全免费托管，适合学生使用
- 后续可轻松扩展小软件

## 本地预览

直接用浏览器打开 `index.html` 即可。

## 部署

已推送到 GitHub，可使用 Cloudflare Pages 免费托管：

1. 登录 [Cloudflare](https://dash.cloudflare.com/)
2. 进入 Pages → 创建项目 → 连接 Git 仓库
3. 选拥本仓库 `personal-records`
4. 框架预设选 **None**
5. 构建命令留空，输出目录填 `/` 或 `.`
6. 部署后获得 `https://xxx.pages.dev` 免费子域名

## 功能

- **日记**：记录标题、内容、时间，支持删除
- **待办**：添加任务、勾选完成、删除
- **目标**：设定目标、描述、进度条（可调整百分比）

数据仅存在于当前浏览器，清除浏览器数据会丢失，建议重要内容另行备份。
